# AEGIS-LOG - Context

AEGIS-LOG is a logistics tracking platform used by a DoW program office to
manage sustainment data for fielded equipment. It runs in an IL4 environment
on AWS GovCloud.

The system you're looking at has been in production for ~3 years and is
currently undergoing its 3-year ATO renewal. The SSP was authored in 2022 and
has been "kept current" with mixed discipline. The infrastructure has evolved
faster than the documentation.

You have two artifacts:
- `ssp.md` - excerpts from the current SSP (NIST 800-53 controls).
- `infrastructure.yaml` - current declared state of production infrastructure.

Both are simplified for this exercise. They are representative, not real.
